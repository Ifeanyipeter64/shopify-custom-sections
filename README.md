# Custom Shopify Sections – Luxury Membership Brand

Custom Liquid sections built for a premium membership brand on Shopify,
designed to match an editorial, luxury aesthetic while staying fully editable
in the theme editor.

## What's included
- **Category grid** – editorial cards, wide feature card, optional heading image, font picker
- **Featured offers** – desktop grid that becomes stacked rows on mobile
- **Promo banner** – desktop and mobile images, text overlay or image-only with full link
- **Partner page template** – members-only content, Gold-tier gating, numbered redemption steps
- **Partner grid** – collection-driven cards, category filter pills, members-only access
- **Custom footer** – logo, menu, newsletter signup (Shopify customer form), social links

## Highlights
- Built with Shopify Liquid, CSS and the theme editor schema
- Fully responsive, with separate mobile layouts and images
- Content managed by the client with no code (metafields and section settings)
- Live text kept for SEO and accessibility
- Access control using customer tags (member and Gold tiers)
